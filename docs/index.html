AI Observer

사용자가 명시적으로 시작한 ChatGPT 응답 측정을 수집하고, 검토 가능한 구조화 JSON 파일로 내보내는 Chrome 확장 프로그램입니다.

독립 제품 안내

AI Observer는 OpenAI 또는 ChatGPT가 제작·승인·후원한 공식 제품이 아닙니다.

주요 기능

  • 질문별 독립 측정과 한 대화의 연속 측정
  • 질문, 답변, 링크, 인용 및 화면 증거 수집
  • 측정 결과의 로컬 JSON 다운로드

데이터 처리

측정은 사용자가 사이드패널에서 직접 시작할 때만 동작합니다. 수집 결과는 외부 서버로 자동 전송되지 않으며 사용자가 자신의 기기에 JSON 파일로 저장합니다.
