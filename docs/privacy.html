개인정보 처리방침

시행일: 2026년 9월 1일 · 게시자: vetron842

AI Observer는 사용자가 요청한 ChatGPT 응답 측정과 JSON 내보내기 기능을 제공하기 위해 아래 정보를 처리합니다.

1. 처리하는 정보

  • 사용자가 측정 중인 ChatGPT 탭의 질문과 답변
  • 답변에 표시된 링크, 인용, 관련 HTML 화면 증거
  • 페이지 URL·제목, 채팅 모드와 화면에 표시된 모델 정보
  • ChatGPT 요청에서 선별한 모델 코드와 모드 신호
  • 사용자가 입력한 질문 세트, 계정 플랜 및 모델 선택 방식

2. 처리 목적

정보는 사용자가 시작한 측정을 구조화하고, 결과를 검토 가능한 JSON 파일로 내보내는 단일 목적으로만 사용합니다. 광고, 사용자 프로파일링 또는 데이터 판매에 사용하지 않습니다.

3. 저장과 전송

AI Observer는 수집한 측정 결과를 게시자 또는 제3자의 서버로 자동 전송하지 않습니다. 설정과 진행 세션은 Chrome 확장 프로그램 저장소에서 로컬로 처리되며, 결과 파일은 사용자가 다운로드를 요청한 경우에만 사용자의 기기에 저장됩니다.

4. 공유와 판매

게시자는 확장 프로그램을 통해 수집한 정보를 제3자와 공유하거나 판매하지 않습니다. 사용자가 직접 내보낸 JSON 파일을 이후에 사용하는 행위는 해당 사용자의 책임과 통제 아래 이루어집니다.

5. 보관과 삭제

진행 세션 정보는 Chrome 세션 또는 로컬 확장 프로그램 저장소에 보관될 수 있습니다. 사용자는 확장 프로그램을 제거하거나 Chrome의 확장 프로그램 데이터를 삭제하여 저장된 설정을 삭제할 수 있습니다. 다운로드한 JSON은 사용자가 직접 삭제할 수 있습니다.

6. 사용자 선택

측정은 사용자가 수집 안내에 동의하고 ‘측정 시작’을 누른 경우에만 시작됩니다. 사용자는 언제든 측정을 중지할 수 있습니다.

7. 제한적 사용 준수

AI Observer가 Chrome API 및 웹사이트에서 얻은 정보는 Chrome Web Store User Data Policy와 Limited Use 요구사항에 따라, 확장 프로그램의 공개된 단일 목적을 제공하거나 개선하는 범위에서만 사용됩니다.

8. 방침 변경

수집 항목이나 사용 목적이 변경되면 이 문서를 갱신하고, 필요한 경우 확장 프로그램 안에서 변경 사항을 고지하고 다시 동의를 받습니다.
