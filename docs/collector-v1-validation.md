# Collector v1 최종 실측

목표는 Collector `0.8.0`의 질문·답변·채팅 모드·계정 플랜·모델 선택 방식·표면적 모델·인용 경계를 여러 조건에서 확인하고 Raw schema v1 고정 여부를 결정하는 것이다.

## 준비

1. `chrome://extensions`에서 AI Observer를 다시 로드한다.
2. 측정에 사용할 ChatGPT 탭을 새로고침한다.
3. 한 번의 측정은 처음 선택한 동일 탭에서 끝까지 진행한다.
4. 독립 질문 측정에서는 `examples/query-set.collector-v1-validation.json`을 불러온다.
5. 실제 계정 플랜과 이번 측정의 모델 선택 방식을 사이드패널에서 지정한다.

## 필수 실측

### A. Max 기본 모델 기준선

- 측정 방식: 여러 질문을 각각 측정
- 채팅 모드: 임시 채팅
- 계정 플랜: Max
- 모델 선택: 기본 모델
- 모델: 네트워크에서 실제 관측된 값을 사용
- 질문: 검증 질문 세트 4개 전체

이 결과는 `Max + 기본 모델` 코호트이며 일반 사용자 전체 기준선으로 부르지 않는다. 일반 사용자 기준선이 필요하면 실제 Free·Plus 계정에서 모델을 직접 고르지 않고 같은 질문 세트를 별도로 측정한다.

### B. 직접 선택 모델 비교

- 측정 방식: 여러 질문을 각각 측정
- 채팅 모드: 임시 채팅
- 계정 플랜: 실제 플랜
- 모델 선택: 직접 선택
- 모델: 사용자가 비교하려는 모델
- 질문: 검증 질문 세트 4개 전체

### C. 채팅 모드 변경

- 측정 방식: 여러 질문을 각각 측정
- 채팅 모드: 일반 채팅
- 계정 플랜: 실제 플랜
- 모델 선택: 기본 모델
- 모델: 네트워크에서 실제 관측된 값
- 질문: 검증 질문 세트 4개 전체

### D. 연속 대화

- 측정 방식: 한 대화를 이어서 측정
- 채팅 모드: 임시 채팅
- 계정 플랜: 실제 플랜
- 모델 선택: 기본 모델
- 첫 질문: `마곡에서 피부과 추천해줘`
- 후속 질문 1: `그중 여드름 치료를 기준으로 비교해줘`
- 후속 질문 2: `오가나셀피부과 마곡점을 추천한 근거와 출처를 알려줘`

## 보조 실측

- 답변 생성 중 중지한 뒤 수동 완료 표시
- 답변 재생성
- Sources 패널을 열기 전과 후 각각 export
- 모델을 질문 사이에 바꾸고 각 turn의 모델이 달라지는지 확인

## 자동 검증

다운로드한 파일을 다음 명령에 한꺼번에 전달한다.

```bash
npm run validate:collector -- \
  ~/Downloads/ai-observer/raw-observation-a.json \
  ~/Downloads/ai-observer/raw-observation-b.json
```

다음을 오류로 판정한다.

- Collector/schema 버전 불일치
- 계정 플랜·모델 선택 방식 누락
- 예정 실행 수와 대화 수 불일치
- 질문·답변·질문별 모델 누락
- 목표 채팅 모드와 실제 모드 불일치
- 임시채팅 네트워크 신호 누락
- 예상 질문과 실제 질문 불일치
- 완료 답변 후보 누락
- 인용 그룹 ID 중복
- 네트워크 요청·토큰 계열 필드 저장
- 지도 저작권 링크의 실제 출처 혼입
- Collector 경고 발생

Normalizer의 미등록 출처 경고는 실측 실패가 아니라 registry 보강 후보로 별도 표시한다.

## v1 확정 기준

- 필수 실측 A~D가 모두 자동 검증을 통과한다.
- 보조 실측의 중지·재생성·Sources 전후 차이를 설명할 수 있다.
- 같은 논리 인용이 후보 개수와 무관하게 하나의 `citation_group`으로 유지된다.
- 계정 플랜·모델 선택 방식·모델·채팅 모드·질문 세트 메타데이터가 보존된다.
- 새 DOM 예외가 발견되어도 raw 증거와 경고로 원인을 추적할 수 있다.
