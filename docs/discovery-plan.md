# ChatGPT 웹 탐사 및 스키마 확정 계획

## 목표

가설로 만든 데이터 필드를 곧바로 제품 계약으로 확정하지 않는다. 탐사용 익스텐션으로 실제 ChatGPT 웹의 DOM, 스트리밍, 인용, Sources 동작을 관측하고 안정성에 따라 raw schema v1을 확정한다.

## 1차 구현 범위

탐사용 Collector는 다음 기능만 제공한다.

1. 사용자가 명시적으로 측정을 시작하고 중지한다.
2. 측정 시작 이후 추가된 질문과 답변 후보를 감지한다.
3. 답변 스트리밍 상태와 완료 후보 시점을 기록한다.
4. 답변 내부 링크, 인용 후보, 접근 가능한 속성을 수집한다.
5. 화면에 표시된 모드·모델 라벨을 가능한 범위에서 기록한다.
6. 선택된 대화 노드의 DOM 스냅샷과 구조화 JSON을 내려받는다.
7. 수집 실패와 모호성을 경고로 남긴다.

이 단계에서는 병원 추천 여부, 주장 분해, 출처 의미 매칭, 점수를 생성하지 않는다.

## 실측 매트릭스

| 케이스 | 확인 목적 |
|---|---|
| 검색 없는 일반 답변 | 기본 질문·답변 및 완료 감지 |
| 웹 검색 답변 | 인라인 인용과 Sources 구조 |
| 여러 병원 추천 | 목록·카드·순서 구조 |
| 인용 여러 개 | 답변 구간과 인용 연결 단위 |
| 후속 질문 | turn 연결과 문맥 구조 |
| 답변 재생성 | 동일 질문의 복수 답변 식별 |
| 답변 중지 | 불완전 응답 상태 |
| 한국어·영어·중국어 번체 | 언어에 따른 DOM·텍스트 차이 |
| Instant·Medium 등 | 모드 표시와 응답 구조 차이 |
| Sources 패널 열기 전·후 | 패널 조작 없이 가능한 수집 범위 |

## 필드 안정성 분류

- `stable`: 반복 케이스에서 안정적으로 관측 가능
- `conditional`: 특정 모드나 답변 유형에서만 존재
- `unstable`: 생성된 class명이나 깊은 DOM 경로처럼 변경 위험이 큼
- `unobservable`: UI에서 확인할 수 없어 수집 계약에서 제외

## 스키마 v1 확정 조건

다음 조건을 모두 충족하면 raw schema v1을 확정한다.

- 핵심 실측 매트릭스의 fixture가 확보됨
- 질문·답변·turn 식별 규칙이 재현됨
- 완료 감지의 오탐·미탐 사례가 기록됨
- 인용 링크와 답변 구간의 연결 가능 범위가 확인됨
- Sources 패널 의존 필드가 구분됨
- UI에서 알 수 없는 정보가 명시적으로 제외됨
- 각 필드가 `stable/conditional/unstable`로 분류됨

## 실측 산출물

```text
fixtures/chatgpt-web/{case-id}/
├── metadata.json
├── raw-observation.json
├── conversation-fragment.html
├── screenshot.png
└── notes.md
```

fixture는 외부 공유나 git 추적 전에 반드시 익명화한다. 전체 개인 대화 HTML이나 인증 정보를 포함하지 않는다.
