# 탐사용 익스텐션 수동 점검표

Chrome 웹 UI는 수시로 바뀔 수 있으므로 릴리스 전 아래 항목을 실제 `chatgpt.com`에서 확인한다.

## 기본 동작

- 익스텐션 아이콘 클릭 시 사이드패널이 열린다.
- ChatGPT가 아닌 탭에서는 연결 안내가 표시된다.
- 설치 전에 열려 있던 ChatGPT 탭에서는 새로고침 안내가 표시된다.
- 측정 시작 전에 존재한 대화는 export에 포함되지 않는다.
- 측정 시작 후 질문과 답변이 role별 후보로 저장된다.
- 측정 중지 후 DOM 변경이 결과에 추가되지 않는다.
- JSON 다운로드 이름에 시각이 포함된다.

## 탐사 케이스

- 검색 없는 일반 답변
- 웹 검색 및 Sources가 있는 답변
- 여러 병원을 목록으로 추천하는 답변
- 인용이 여러 개인 답변
- 후속 질문
- 답변 재생성
- 사용자가 중지한 불완전 답변
- 한국어, 영어, 중국어 번체
- 사용 가능한 각 모델 및 모드
- Sources 패널을 열기 전과 후

## 개인정보 확인

- 쿠키, 세션 토큰, 이메일 주소가 결과에 없는지 확인한다.
- fixture로 저장하기 전에 이름, 병력, 연락처 등 민감 정보를 익명화한다.
- 전체 대화 URL을 보존할 필요가 없으면 fixture의 `page.url`을 제거하거나 익명화한다.
