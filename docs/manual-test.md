# 탐사용 익스텐션 수동 점검표

Chrome 웹 UI는 수시로 바뀔 수 있으므로 릴리스 전 아래 항목을 실제 `chatgpt.com`에서 확인한다.

## 기본 동작

- 익스텐션 아이콘 클릭 시 사이드패널이 열린다.
- ChatGPT가 아닌 탭에서는 연결 안내가 표시된다.
- 설치 전에 열려 있던 ChatGPT 탭에서는 새로고침 안내가 표시된다.
- 측정 시작 전에 존재한 대화는 export에 포함되지 않는다.
- 측정 시작 후 질문과 답변이 role별 후보로 저장된다.
- 측정 중지 후 DOM 변경이 결과에 추가되지 않는다.
- JSON 다운로드 이름에 시각이 포함된다.
- 각 답변의 `last_text_changed_at`과 완료 판정 증거가 기록된다.
- 완료된 답변 대부분이 `quiet_candidate`로 기록된다.
- 인용 하나의 pill과 link가 같은 `citation_group`으로 묶인다.
- `citation_groups.length`가 화면에서 보이는 논리 인용 수와 일치한다.
- 모델·응답 모드가 값과 DOM 증거로 기록되거나 탐사용 UI 후보가 남는다.
- 새 임시 채팅에서 **새 대화로 분리**를 누르면 `conversation_instance_id`가 바뀐다.
- 독립 질문 대화에 질문이 두 개 이상이면 `independent_query_turn_count` 경고가 생긴다.
- 연속 대화에서는 여러 turn이 하나의 `conversation_instance_id`에 연결된다.
- 새 채팅의 `regular → temporary` 전환은 별도 대화가 아니라 질문 전 설정 이력으로 남고, 질문 시점의 실질 모드는 `temporary`가 된다.

## 질문 세트 Runner

- 일반 입력창에 한 줄당 하나씩 질문을 넣고 **질문 준비**를 누르면 질문 수와 전체 측정 횟수가 표시된다.
- 반복 횟수를 2로 지정하면 모든 질문이 각각 2회씩 실행 큐에 들어간다.
- JSON 입력은 기본 화면이 아니라 접힌 **JSON으로 가져오기(고급)** 안에 표시된다.
- 유효한 JSON을 불러오면 `repetitions`를 포함한 전체 실행 수와 첫 질문이 표시된다.
- 중복 `query_id`, 빈 질문, 1~20 범위 밖의 반복 횟수는 거부된다.
- **질문 복사**가 현재 표시된 질문만 클립보드에 넣는다.
- 현재 질문을 ChatGPT에 전송하면 사이드패널이 다음 질문을 자동으로 표시하고 즉시 복사할 수 있다.
- 다음 질문이 미리 표시되어도 현재 답변은 기존 `conversation_instance_id`에 계속 연결된다.
- **다음 질문 준비**는 현재 답변이 완료 후보가 된 뒤에만 활성화된다.
- 측정 중 **다음 질문으로 분리**를 누르면 `conversation_instance_id`와 현재 `query_id`가 함께 바뀐다.
- 사이드패널을 닫았다 다시 열어도 현재 질문 순서가 유지된다.
- 내려받은 JSON의 각 `conversation_instances[].query`에 질문 ID, 분류, 반복 번호가 기록된다.
- 실제 질문이 예상 질문과 다르면 `prompt_match: mismatch`와 `query_prompt_mismatch` 경고가 기록된다.
- Normalizer 출력에서 질문 세트 메타데이터가 measurement, conversation, turn에 보존된다.

## 탐사 케이스

- 검색 없는 일반 답변
- 웹 검색 및 Sources가 있는 답변
- 여러 병원을 목록으로 추천하는 답변
- 인용이 여러 개인 답변
- 후속 질문
- 답변 재생성
- 사용자가 중지한 불완전 답변
- 한국어, 영어, 중국어 번체
- 사용 가능한 각 모델 및 모드
- Sources 패널을 열기 전과 후

## 개인정보 확인

- 쿠키, 세션 토큰, 이메일 주소가 결과에 없는지 확인한다.
- fixture로 저장하기 전에 이름, 병력, 연락처 등 민감 정보를 익명화한다.
- 전체 대화 URL을 보존할 필요가 없으면 fixture의 `page.url`을 제거하거나 익명화한다.
