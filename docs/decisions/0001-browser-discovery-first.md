# ADR-0001: 브라우저 탐사를 스키마 확정보다 먼저 수행한다

- 상태: 승인
- 날짜: 2026-08-14

## 배경

ChatGPT 웹과 OpenAI API는 서로 다른 제품 표면이며 얻을 수 있는 데이터가 다르다. ChatGPT 웹의 질문·답변·인용·Sources 구조는 실제 DOM과 사용자 모드에 따라 달라질 수 있다. 실측 없이 구체적인 raw schema를 확정하면 수집할 수 없는 필드나 잘못된 의미를 계약으로 고정할 위험이 있다.

## 결정

첫 구현은 진단 엔진이 아니라 탐사용 Chrome 익스텐션으로 한다. 익스텐션은 화면에서 관측 가능한 원본 후보와 DOM 증거만 수집한다. 추천, 주장-출처 의미 매칭, 종합 점수는 raw schema v1 확정 이후 구현한다.

## 결과

- 초기 기능은 작지만 실제 수집 가능성에 근거해 스키마를 정할 수 있다.
- DOM 변경에 취약한 필드와 안정적인 필드를 구분할 수 있다.
- 진단 결과 출시는 한 단계 늦어지지만 잘못된 데이터 계약을 줄인다.
- 이후 수집 채널이 추가되어도 raw → normalized 경계를 유지한다.
